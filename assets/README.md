# assets: built-in pictures and data

Built into the kernel when it's compiled.

|---|---|
| `wallpapers/` | The five desktop photos (autumn, field, forest, snow, sunset), CC0 from Wikimedia Commons; see [CREDITS.md](wallpapers/CREDITS.md). `thumbs/` holds their small previews for Settings |
| `spell/` | The spelling dictionary (`en.dict`), made from SCOWL's word lists by `tools/spell/mkdict.py`; see [SCOWL-Copyright.txt](spell/SCOWL-Copyright.txt) |
