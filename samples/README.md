# samples: test photos

Synthetic photos for development boots (`run.sh`, `test.sh`), made by
`tools/make-samples.ps1`: assorted sizes and shapes, a PNG with see-through parts, a tiny one,
and two files that are broken on purpose (`broken.jpg`, `unreadable.jpg`) to check that Solon
shows a problem instead of crashing. They aren't on the USB image.
